# Glossary

Canonical term definitions for kAY.am. Use these in code, UI, docs, and issues.

| Term                         | Definition                                                                                                                                                                                                                                                                                                                               |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **workspace**                | A registered git repository directory. Sessions are scoped to a workspace and run inside isolated worktrees alongside the repo.                                                                                                                                                                                                          |
| **session**                  | A goal-oriented container inside a workspace. Owns the git worktree, the branch, the shared context slots, the budget, and the list of agents. Auto-spawns one default agent on creation. _DB table:_ `tasks` (legacy name; types still use `Task` / `TaskId`).                                                                          |
| **agent**                    | An independent chat thread inside a session. Has its own provider/model, its own message history, and its own status (pending / running / completed / failed). User spawns agents from the sidebar at will; rename inline via the pencil icon. _DB table:_ `sessions` (legacy name; types still use `Session` / `SessionId`).            |
| **shared context**           | The synthetic slots (goal, files touched, decisions, open questions, last summary) attached to a session. Visible in the right-side context panel; auto-populated by the summarizer after every agent turn. All agents in the session read the same context.                                                                             |
| **workflow** _(beta)_        | An optional preset that pre-spawns N named agents at session creation (e.g. scout → planner → implementer → reviewer). Comes from the seeded library, settings authoring, or the planner agent ("design custom" chip). After spawn, the agents are independent and live alongside any free-form ones. _DB table:_ `workflows` + `steps`. |
| **step**                     | One agent role inside a workflow. Carries a name, a prompt prefix, and optional provider/model overrides. Becomes the seed for one pre-spawned agent.                                                                                                                                                                                    |
| **planner**                  | A cheap-tier provider call that turns a free-text theme into a `PlannerOutput` (workflow name + ordered steps). Surfaced as the "design custom" chip in the new-session dialog.                                                                                                                                                          |
| **worktree**                 | The git worktree directory for a session — the path on disk where files live while the session is active. Removed when the session ends; the branch is preserved.                                                                                                                                                                        |
| **branch**                   | The git branch the worktree checks out. Named `<prefix>/<slug>` by default. Preserved after the session ends for manual review or merge.                                                                                                                                                                                                 |
| **skill**                    | A markdown + scripts automation invocable from chat via `/skill-name`. Discovered from `<workspace>/.kay/skills/*.md` or `<workspace>/.claude/skills/<name>/SKILL.md`; auto-rescanned on workspace add. Per-workspace, not global.                                                                                                       |
| **permission rule** _(beta)_ | A matcher pattern for tool-call interception. Determines whether a tool invocation is allowed, denied, or requires confirmation.                                                                                                                                                                                                         |
| **turn**                     | One user prompt → one assistant response, including all streaming events in between. The atomic unit of interaction within an agent.                                                                                                                                                                                                     |
| **parallel group** _(beta)_  | Multiple agents executing in parallel on throwaway worktrees, merged back at completion. Workflow-driven; opt-in via global settings → Agent.                                                                                                                                                                                            |
| **initialization (db wipe)** | Settings → Initialization → "Wipe local database". Drops every workspace / session / agent / message in `~/.kay-am/data.db` and re-runs migrations on next boot. API keys in the OS keychain are not touched.                                                                                                                            |
