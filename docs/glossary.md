# Glossary

Canonical term definitions for kAY.am. Use these in code, UI, docs, and issues.

| Term                | Definition                                                                                                                                                                                                                                                 |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **workspace**       | A registered repository directory. The root git repo kAY.am tracks and creates tasks inside.                                                                                                                                                               |
| **task**            | A goal-oriented container inside a workspace. Holds context slots, the chosen workflow, branch info, and aggregated telemetry. Renamed from "session" in the pre-1.0 cleanup; older docs may still say "session" at the goal level.                        |
| **workflow**        | A blueprint of ordered steps a task runs. Workflows come from the seeded library, settings authoring, or the planner agent ("design custom" chip). Renamed from "phase template".                                                                          |
| **step**            | One agent role inside a workflow (e.g. scout, planner, implementer, reviewer). Carries a prompt prefix and an expected output hint. Renamed from "phase definition".                                                                                       |
| **session**         | One atomic CLI run for a step inside a task. Has a status (pending / running / completed / failed / skipped), a provider run id, and an output summary. Multiple sessions can execute the same step (retries, parallel fan-out). Renamed from "phase run". |
| **agent**           | UI label for a Session — the unit of work surfaced in the sidebar's third block. Each step in the running workflow becomes an agent in the agents list, with its own status and (eventually) scope chips and sub-agents.                                   |
| **parallel group**  | Multiple sessions executing in parallel on throwaway worktrees, merged back at completion. Renamed from "parallel phase group".                                                                                                                            |
| **planner**         | A cheap-tier provider call that turns a free-text theme into a `PlannerOutput` (workflowName, reasoning, ordered steps with role + expectedOutput). Surfaced as the "design custom" chip in the new-task wizard.                                           |
| **worktree**        | The git worktree directory for a task — the path on disk where files live while the task is active. Removed when the task ends; the branch is preserved.                                                                                                   |
| **branch**          | The git branch the worktree checks out. Named `<prefix>/<slug>` by default. Preserved after the task ends for manual review or merge.                                                                                                                      |
| **skill**           | A markdown + scripts automation invocable from chat via `/skill-name`. Discovered from `<root>/.kay/skills/*.md` or `<root>/.claude/skills/<name>/SKILL.md`; auto-rescanned on workspace add. Provider-agnostic.                                           |
| **permission rule** | A matcher pattern for tool-call interception. Determines whether a tool invocation is allowed, denied, or requires confirmation.                                                                                                                           |
| **turn**            | One user prompt → one assistant response, including all streaming events in between. The atomic unit of interaction within a session.                                                                                                                      |
