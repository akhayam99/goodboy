# Custom window events

> **Read this when** dispatching or listening for custom window events in apps/desktop. **Not for** Tauri inter-window communication or other message protocols (`docs/worktree-bridge.md`).

Every event on this page is a browser CustomEvent. It is sent with `window.dispatchEvent()` and received with `window.addEventListener()`. The payload is the `detail` field.

## Adding an event

Event names follow the pattern `goodboy:verb-noun` (for example `goodboy:open-plan-studio` or `goodboy:reveal-chat`). Every event must be dispatched and listened to in the same pull request. A listener with no dispatch is unreachable code. Keep payloads small. Pass only the ids and enums a feature needs to route or start up, never whole objects. If an event grows past three fields, ask whether the routing logic belongs in a store method instead.
