# Review a pull request with comments in place

Reviewers left comments on pull request 318 of Harborline, and you want them answered in one push.

1. Open the session, click the branch under **Projects**, then open **Comments**.
2. Read the groups: **Needs you**, **Working**, **Ready to push**, **Done** and **Left open**.
3. Open a comment. The drawer shows the code around the line, the comment and its thread.
4. Press **Fix** to start an agent on it. **Reply** and **Skip** sit beside it. To handle many at once, check the ones you want and press **Fix N comments** in the Branch header.
5. Accept, edit or skip each result. A question from the agent shows in **Needs you**.
6. Press **Push** in the Branch header. The confirm counts the fixes, replies and threads to resolve, and one **Push** sends them.

Why it works: replies, fixes and resolved threads leave together, and only after you have read them.

See [Review and resolve](../features/review.md) for hints, tones and failed drafts.
