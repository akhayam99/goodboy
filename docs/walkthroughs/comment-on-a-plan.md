# Comment on a plan, then run it

A planner drafted a plan for Harborline to stop retried webhooks posting a second credit. You want it right before any agent starts.

1. Open the session and its **Artifacts** page, then pick the **Plans** tab.
2. Open the plan.
3. Point at a part, a paragraph or a few words, and leave a comment. Comments stay drafts.
4. Press **Send to planner**. It posts your comments in plan order and asks for an updated plan.
5. When the new version lands, each comment reads **Addressed** or **Not changed in v2**.
6. Check the done-when checks and the files each part expects to touch. Press **Run plan**.

Each part of the plan becomes a sub-agent. On a plan that came from a workflow, the button reads **Approve** and continues that workflow.

Why it works: you settle the plan before it runs, and each comment shows whether the new version answered it.
